# AI エージェント体験コース 練習用リポジトリ

今日は、AI エージェント（GitHub Copilot の Agent モード）に作業を 1 つ任せてみます。

## 安全に試すための 3 つの約束

1. **使い捨ての場所で試す**。今開いているこの画面（Codespace）は、あなた専用の使い捨ての PC です。何が起きても、あなたの PC やファイルには影響しません
2. **実行前に中身を見る**。AI が「実行していいか」と聞いてきたら、何をするのか読んでから承認してください
3. **社外秘を入れない**。業務の情報や個人情報は入力しないでください

## 準備

1. 「このフォルダー内のファイルの作成者を信頼しますか?」と聞かれたら、**はい、作成者を信頼します** を押す（事前準備で済ませた人は出ません）
2. Copilot のアイコンを押して、チャットの欄を開く
3. チャット欄の下にあるモードの切り替えで **Agent** を選ぶ

## お題

上から順に、チャット欄に入力してください。文言は自由に変えてかまいません。

AI が作業している間、英語の文章が流れることがあります。これは AI が考えている途中の様子です。読まなくてかまいません。最後に出る日本語の回答を読んでください。

### お題 1: 中身を説明してもらう

```
このフォルダには何が入っている？
```

AI がファイルを読んで答えます。

### お題 2: 同じお願いを 2 つのモードで見比べる

```
名前を「（あなたの名前）」、趣味を「（あなたの趣味）」にして、背景を秋っぽい色にして
```

（　）の中は自分のことに書き換えてください。ニックネームでかまいません。

1. まず、チャット欄の下のモードを **Ask** にして送ってください。直し方が文章で返ってきますが、`index.html` は変わりません。答えの中に出るボタンは押さないでください
2. 次に、モードを **Agent** に戻して、同じ文を送ってください。AI が `index.html` を書き換えます。変更箇所（差分）を見て、よければ **Keep**、取り消すなら **Undo** を押してください

### お題 3: 自分で考えて、機能を 1 つ足してもらう

ページに足したい機能を自分で考えて、次の形で頼んでください。最後の「動作確認もして」は必ず付けてください。

```
〇〇ボタンを押すと、△△するようにして。動作確認もして
```

思いつかないときは、この中から選んでかまいません。

- おすすめのランチがランダムに出る
- 今日の運勢が出る
- 背景の色が変わる
- 押した回数が数えられる

大きさの目安は「ボタン 1 つで動くくらいの小さな機能」です。時間内に終わらなかったら、勉強会の後に続きをしてかまいません。

AI がページを表示するためのコマンドを実行してよいか聞いてきます。内容を読んでから承認してください。

ページは次の手順で開きます（ダウンロードは不要です）。

1. 画面下のパネルの **ポート**（Ports）タブを開く
2. 8000 番の行にある地球儀のアイコン（ブラウザーで開く）を押す
3. 新しいタブでページが開いたら、ボタンを押して確かめる

AI が「動作確認しました」と言っても、AI はブラウザでボタンを押したわけではありません。**最後は自分の目で確かめる**のが、AI に仕事を任せるときの基本です。

画面右下に「ポート 8000 で実行中のアプリケーションを利用できます」と出たときは、その **ブラウザーで開く** からでも開けます。

## 終わったら

この Codespace を削除します。

1. ブラウザで https://github.com/codespaces を開く
2. 今日使った Codespace の右にある「…」→ **Delete** を押す

削除しなくても 30 日たつと自動で消えますが、無料で使える保存容量を消費し続けます。
