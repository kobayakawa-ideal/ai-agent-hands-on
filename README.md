# AI エージェント体験コース 練習用リポジトリ

今日は、AI エージェント（GitHub Copilot の Agent モード）に作業を 1 つ任せてみます。

## 安全に試すための 3 つの約束

1. **使い捨ての場所で試す**。今開いているこの画面（Codespace）は、インターネットの向こうに借りた、練習専用のパソコンです。あなたのパソコンとは別物なので、中で何が起きても、あなたのパソコンやファイルには影響しません。終わったら丸ごと消せます
2. **実行前に中身を見る**。AI が「実行していいか」と聞いてきたら、何をするのか読んでから承認してください
3. **社外秘を入れない**。業務の情報や個人情報は入力しないでください

## 準備

1. 「このフォルダー内のファイルの作成者を信頼しますか?」と聞かれたら、**はい、作成者を信頼します** を押す（事前準備で済ませた人は出ません）
2. Copilot のアイコンを押して、チャットの欄を開く（初めから開いているときは、そのままでかまいません）
3. ページを見られるようにする。画面の下にある **ターミナル**（Terminal）のタブを押し、次の 1 行を入力して Enter キーを押す（ターミナルは、文字で指示を打ち込む場所です。見当たらないときは、左上の「≡」→「ターミナル」→「新しいターミナル」）

   ```
   python3 -m http.server 8000
   ```

4. 右下に出るお知らせの **ブラウザーで開く**（Open in Browser）を押す。新しいタブに自己紹介のページが開けば成功です。お知らせが消えたときは、画面の下の **ポート**（Ports）タブを開き、8000 番の行にある地球儀のアイコンを押す

このあと、ターミナルは閉じずにそのままにしておいてください。ページのタブも開いたままにします。ページが開けないときは、講師の画面を見ながら進めて大丈夫です。

## お題

上から順に、チャット欄に入力してください。文言は自由に変えてかまいません。

AI が作業している間、英語の文章が流れることがあります。これは AI が考えている途中の様子です。読まなくてかまいません。最後に出る日本語の回答を読んでください。

### お題 1: 中身を説明してもらう

```
このフォルダには何が入っている？
```

AI がファイルを読んで答えます。

### お題 2: ページを書き換えてもらう

```
名前を「（あなたの名前）」、趣味を「（あなたの趣味）」にして、背景を秋っぽい色にして
```

（　）の中は自分のことに書き換えてください。ニックネームでかまいません。

1. 送ると、AI が `index.html` を書き換えます。変わった所に色が付くので、中身を見て、よければ **Keep**（残す）、取り消すなら **Undo**（元に戻す）を押してください
2. 「準備」で開いたページのタブに切り替えて、再読み込み（F5 キー）してください。名前・趣味・背景の色が変わっていれば成功です

### お題 3: 自分で考えて、機能を 1 つ足してもらう

ページに足したい機能を自分で考えて、次の形で頼んでください。最後の「動作確認もして」は必ず付けてください。

```
〇〇ボタンを押すと、△△するようにして。動作確認もして
```

思いつかないときは、この中から選んでかまいません。

- おすすめのランチがランダムに出る
- 今日の運勢が出る
- 背景の色が変わる
- 押した回数が数えられる

大きさの目安は「ボタン 1 つで動くくらいの小さな機能」です。時間内に終わらなかったら、勉強会の後に続きをしてかまいません。

AI が途中で、コマンドを実行してよいか聞いてくることがあります。何のために、何をするのかを読んでから承認してください。分からないときは承認せずに、AI に「これは何？」と聞いてください。

AI の作業が終わったら、「準備」で開いたページのタブに切り替えて再読み込み（F5 キー）し、足したボタンを自分で押して確かめてください。

AI が「動作確認しました」と言っても、AI はブラウザでボタンを押したわけではありません。**最後は自分の目で確かめる**のが、AI に仕事を任せるときの基本です。

ページのタブを閉じてしまったときは、画面の下の **ポート**（Ports）タブを開き、8000 番の行にある地球儀のアイコンを押すと開き直せます。

## 終わったら

この Codespace を削除します。

1. ブラウザで https://github.com/codespaces を開く
2. 今日使った Codespace の右にある「…」→ **Delete** を押す

削除しなくても 30 日たつと自動で消えますが、無料で使える保存容量を消費し続けます。
